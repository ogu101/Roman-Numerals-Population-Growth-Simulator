<h2>Overview</h2>
This project is a menu-driven Python program that allows users to interact with two core functionalities:

- Roman Numerals Converter – Users can input a number between 1 and 10 to see its corresponding Roman numeral.

- Population Growth Predictor – Users can simulate organism population growth over a set number of days, given a starting population size, an average daily increase percentage, and a time duration.
